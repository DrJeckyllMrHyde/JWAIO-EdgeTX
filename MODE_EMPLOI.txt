JWAIO v0.3.1 — PREMIÈRE INSTALLATION

Téléchargements :
https://github.com/DrJeckyllMrHyde/JWAIO-EdgeTX/tree/main/releases/v0.3.1

CHOISIR UNE SEULE VARIANTE
TX15/TX15 Max ; TX16S Mk1/Mk2 ; ou TX16S Mk3.
TX15 et Mk1/Mk2 ont été testés et sont fonctionnels pour tous les usages selon
le créateur. Des correctifs mineurs et optimisations restent possibles.
Le créateur ne possède pas de Mk3 : adaptation aux spécifications matérielles
RadioMaster, sans essai physique. EdgeTX 2.12.0 ou supérieur requis ; testeurs
Mk3 recherchés. La série visée est 2.12.x, sans garantie de chaque version future.
La mention 3.0.0 dans les notices originales Mk3 est clarifiée ici :
https://github.com/DrJeckyllMrHyde/JWAIO-EdgeTX/blob/main/docs/COMPATIBILITE.md

INSTALLER
1. Sauvegarder le stockage, le modèle EdgeTX, les réglages JWAIO et les journaux.
2. Décompresser le ZIP de votre radio sur l'ordinateur.
3. Mk1/Mk2 : ouvrir JWAIO-v0.3.1_TX16S-Mk1-Mk2 pour voir WIDGETS, SOUNDS, LOGS.
   TX15 et Mk3 : ces trois dossiers sont directement dans le paquet extrait.
4. Brancher le port USB de données de la radio et choisir Stockage USB.
5. Copier WIDGETS, SOUNDS et LOGS à la racine du volume utilisé par EdgeTX.
   Fusionner les dossiers ; remplacer les fichiers JWAIO après sauvegarde.
   Ne pas formater ni supprimer les fichiers des autres widgets.
6. Vérifier : /WIDGETS/JWAIO/main.lua, /SOUNDS/fr/JWAIO/, /LOGS/JWAIO/.
   Aucun dossier portant le nom du ZIP ne doit entourer WIDGETS sur la radio.
7. Éjecter le volume proprement puis redémarrer la radio.
8. Sélectionner le modèle ; véhicule connecté, hélices retirées, découvrir ses
   capteurs dans la page Télémétrie puis arrêter la découverte.
9. Configurer un écran à une seule grande zone ; choisir le widget JWAIO.
   Une seule instance par modèle. Privilégier le plein écran.
10. Régler les dix options et vérifier le fonctionnement au sol.

LES DIX OPTIONS
Skin : JWAIO fourni.
BatType : batterie du véhicule, LiPo, LiIon ou LiHv.
Cells : nombre réel de cellules (1 à 8 ; 6 par défaut).
LinkType : ELRS ou TBS_CF ; ne renomme pas automatiquement les capteurs.
ARM : position qui arme déjà votre modèle.
PreArm : position du pré-armement si utilisé.
Beeper : position d'activation du beeper, sinon désactivée.
Flip : position du retournement après crash, sinon désactivée.
RTH : position du retour GPS déjà configuré, sinon désactivée.
Thr : voie des gaz réelle ; CH3 proposée par défaut.

Vérifier les commandes : ARM recherche SE bas, PreArm SF bas. SA bas affiche
ANGLE, SA haut/milieu ACRO ; RTH est prioritaire. Ces indications suivent les
commandes, pas une confirmation du contrôleur de vol. JWAIO ne configure pas
l'armement, le beeper ou le retour GPS du drone.

CAPTEURS ET MINUTERIES
RxBt : batterie ; RQly : LQ ; 1RSS : RSSI ; GPS : position du véhicule ;
Alt : altitude en mètres ; GSpd : vitesse en km/h ; Sats : satellites.
Les noms et speedMultiplier sont ajustables dans /WIDGETS/JWAIO/config.lua.
Redémarrer après une modification des capteurs ou de la configuration.
Sans GPS, batterie et liaison restent utilisables ; NO_DATA signifie une donnée
absente ou invalide. Satellites valides : 0–4 rouge, 5–6 orange, 7+ vert.
TIMER 1 : compteur montant de vol, remis à zéro désarmé par JWAIO.
TIMER 2 : cumul conservé par JWAIO ; configurer la persistance dans EdgeTX.
Configurer la condition de marche de chaque minuterie dans le modèle EdgeTX.

FINDER ET SONS
Beeper, Flip ou RTH active le Finder ; les trois doivent être inactifs pour
l'arrêter. Les bips suivent la force du signal, sans distance/direction garantie.
Pendant la recherche, les autres annonces JWAIO, y compris batterie critique,
sont différées ou supprimées selon leur état. Les confirmations Beeper/Flip/RTH
restent autorisées. Ne pas compter sur une relecture systématique des alertes.
Éviter les doublons avec les annonces configurées dans EdgeTX.

MISE À JOUR ET DÉPANNAGE
Si l'ancien menu n'avait pas Skin, retirer puis recréer l'instance JWAIO.
Toujours vérifier toutes les options. Reporter les personnalisations dans le
nouveau config.lua plutôt que le remplacer par l'ancien fichier complet.
Widget absent : vérifier le chemin et le volume, puis redémarrer.
NO_DATA : vérifier connexion, découverte et noms des capteurs.
Pas de sons : vérifier volume, dossier SOUNDS/fr/JWAIO et Finder inactif.
Temps immobile : vérifier la condition de marche des minuteries EdgeTX.
Conserver les journaux /LOGS/JWAIO/ ; retirer les coordonnées avant partage.
Les effets LED sont optionnels, désactivés par défaut ; commencer ainsi.
