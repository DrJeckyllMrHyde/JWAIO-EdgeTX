# Télécharger JWAIO v0.3.1 Alpha

J'ai testé les versions TX15 et TX16S Mk1/Mk2 avec succès. Elles sont fonctionnelles pour tous les usages ; de petits correctifs et des optimisations restent possibles.

| Radio | Archive | État des essais |
|---|---|---|
| TX15 / TX15 Max | [Télécharger](JWAIO-v0.3.1-Alpha-TX15.zip?raw=true) | Testée positivement |
| TX16S Mk1 / Mk2 | [Télécharger](JWAIO-v0.3.1-Alpha-TX16S-Mk1-Mk2.zip?raw=true) | Testée positivement |
| TX16S Mk3 | [Télécharger](JWAIO-v0.3.1-Alpha-TX16S-Mk3.zip?raw=true) | Pas d'essai physique |

Je ne possède pas de Mk3. J'ai adapté le widget aux spécifications matérielles RadioMaster et je recherche des testeurs. EdgeTX 2.12.0 ou supérieur est requis ; la série visée est 2.12.x.

Choisissez uniquement le ZIP de votre radio. Après sauvegarde, copiez WIDGETS, SOUNDS et LOGS à la racine du stockage EdgeTX. Le mode d'emploi et les licences sont inclus. Les téléchargements automatiques « Source code » ne sont pas des paquets d'installation.

Sur TX15, les LED du skin JWAIO sont activées par défaut. Consultez le [guide des LED](../../docs/SKINS.md#led-du-skin-jwaio-sur-tx15) pour les personnaliser ou les couper. Les LED restent désactivées par défaut sur TX16S.
