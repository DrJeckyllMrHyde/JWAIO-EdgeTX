JWAIO 0.3_Alpha - JECKYLL WIDGET ALL IN ONE
RadioMaster TX15 Max / EdgeTX 2.12.x - Base technique : 0.3.0 alpha-2.

Copiez WIDGETS, SOUNDS et LOGS a la racine du stockage utilise par la radio,
en fusionnant les dossiers. Sauvegardez ce stockage avant installation.
Ne le formatez pas. Consultez MODE_EMPLOI.txt pour installer ou supprimer JWAIO.

Ajoutez JWAIO puis configurez les dix options, en particulier les switches.
Skin est la premiere option. Si l'ancien menu persiste, retirez le widget
de son emplacement puis ajoutez-le a nouveau.

Decouvrez les capteurs : RxBt, RQly, 1RSS ; GPS, Alt, GSpd, Sats si disponibles.
Une donnee absente ou perimee affiche NO_DATA.
Le widget ne commande ni les moteurs ni les modes de vol.

Skins : /WIDGETS/JWAIO/skins/ ; JWAIO fourni sert de secours.
Fond PNG 480 x 320 ; logo PNG 216 x 132 ; manifeste skin.lua.
Guide complet : docs/SKINS.md sur le depot.

Journaux prives : /LOGS/JWAIO/ ; ne publiez pas vos coordonnees.
