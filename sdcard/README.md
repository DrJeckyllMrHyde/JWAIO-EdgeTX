# Dossier historique 0.3.0-alpha

Ce dossier contient la base historique TX15 0.3.0-alpha. Il ne représente pas les trois paquets publiés pour v0.3.1.

Pour installer **JWAIO v0.3.1**, téléchargez l'[archive correspondant à votre radio](../releases/v0.3.1/README.md) et suivez le [guide d'installation](../docs/INSTALLATION.md). Ne copiez pas ce dossier historique à la place du ZIP v0.3.1.

Les outils de construction et les tests historiques du dépôt restent associés à cette base. Les ZIP v0.3.1 fournis par le créateur sont publiés à l'identique.
